# Security Policy

## Supported Versions

SagaCraft is currently maintained on the latest `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest on `main` | ✅ |
| Older snapshots/releases | ⚠️ Best effort |

## Reporting a Vulnerability

If you discover a security issue, please do **not** open a public issue first.

Instead, use one of the following options:

1. Open a private report through GitHub Security Advisories:
   https://github.com/James-HoneyBadger/SagaCraft/security/advisories/new
2. Contact the maintainer directly at: james@honey-badger.org

Please include:

- A clear description of the issue
- Steps to reproduce it
- The affected component or crate
- Any suggested remediation, if known

## Response Process

The project will aim to:

- Acknowledge reports promptly
- Validate and reproduce the issue
- Prepare and publish a fix when confirmed
- Credit the reporter when appropriate and desired
