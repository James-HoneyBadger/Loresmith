# Political Showcase Adventure

A new political-intrigue example adventure has been added to the workspace.

## Included file

Path: iron_assembly_showcase.json

## Theme

The Iron Assembly is a showcase centered on:
- rival noble houses
- public unrest and reform movements
- legal archives and succession disputes
- secret funding networks and blackmail
- high-stakes council votes
- diplomacy, investigation, and selective combat

## Highlights

- 16 interconnected locations
- friendly, neutral, and hostile political actors
- readable evidence items and symbolic treasures
- multiple long-form quests covering investigation, coalition-building, and endgame confrontation
- suitable for demonstrating talk, ask, quest, save/load, and autosave features

## Quick start

cargo run --bin sagacraft_player -- iron_assembly_showcase.json
